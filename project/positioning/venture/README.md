## seed copy from keeberia-front

extracted from kqrla/keeberia-front src/routes/index.tsx, philosophy.tsx, about.tsx, roadmap.tsx, sept 25 2026.

- one-sentence thesis: keeberia is a spatial hardware design platform that lets you visually create custom keyboards and input devices, then automatically translates those designs into manufacturable pcb, case, and firmware outputs.
- platform positioning: a browser-based design environment for custom macropads, encoder decks, and small keyboards. start with layout and interaction — pcb, case, and firmware are generated behind the scenes.
- category shift: instead of electronics → cad → manufacturing, keeberia goes layout → identity → fabrication. feels like figma, notion, canva, or modular building systems rather than engineering software like kicad or fusion 360.
- expansion roadmap: from macropad-first to a full modular human-interface design platform — extending to split keyboards, ergonomic keyboards, modular desk controllers, midi controllers, industrial interfaces, custom tactile devices, and embedded display systems.
- interface philosophy: calm, modular, spatial, visual, and approachable. hardware design as an exploratory, creative productivity tool rather than procedural cad software.
