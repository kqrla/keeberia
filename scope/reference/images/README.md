# reference images

anne dropped these in on sept 25 alongside the layout-standards / dual-legend
research push. no source urls attached, so these are working visual reference
for the team, not evidence.jsonl entries: use them to sanity-check the research
docs, not as citable claims.

## artisan-skull-caps.jpg

the artisanal keycap example anne meant. resin multi-shot skull sculpts on
what looks like a mac/win hybrid board. matches scope/research/artisan-scene.md
section 2 (multi-shot pressure casting) almost exactly: layered colored resin,
no surface paint, sharp small-scale detail. good sanity check that our
artisan-scene research already describes the real thing.

## layout-ansi-diagram.png / layout-iso-diagram.png

paired reference diagrams for research/layout-standards.md (phase 7). shows
the concrete physical difference the doc argues for: iso has the extra key
next to left shift plus the taller two-row enter (highlighted red in both
diagrams), ansi has the wider single-row enter and no extra key. both share
tab/capslock/os/menu/altgr placement otherwise. worth linking directly from
the companion doc.

## clusters-generic.png / layout-clusters-colorcoded-mac.png

two different color-coded cluster maps: one generic (alphanumeric/function/
nav/numpad, ansi-shaped), one mac-flavored (esc, media row, mic/lock icons,
option/command modifiers, green arrow cluster). useful less for fab rules and
more for the editor/product side: if keeberia's builder ui groups keys by
cluster (the way these diagrams do), this is a ready-made visual language for
that grouping, worth a pointer from scope/product.md or the frontend editor
work when that's scoped.

## dual-legend-bengali.png / dual-legend-serbian-cyrillic.png / dual-legend-hebrew.png

three concrete examples of the phase 8b question: every key carries a large
primary script character plus a small secondary latin one. bengali (already
the reference that started 8b), serbian cyrillic (latin secondary in the same
top-right convention), and hebrew (rtl primary script, but the secondary latin
stays in the same corner position regardless of the primary's writing
direction, worth confirming against evidence once the 8b worker reports back).
these three are the direct visual grounding for research/dual-legend-multilingual.md
once that doc lands: they show the print convention is consistent across
otherwise unrelated scripts, which is exactly the kind of claim that doc needs
sourced, not just eyeballed from one keyboard.
