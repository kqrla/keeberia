# paracraft

**paracraft** — the scad engine. the parametric case compiler (and, later, keycaps + knob covers): `pcb result → openscad source`. pure, synchronous, deterministic — same input, same case, forever.

```
backend/engines/paracraft/
  src/index.ts        generateCase(pcb, options?) → { scad, params, warnings, stats }
  test/render.ts      reference boards → out/*-case.scad (+ stl when openscad is available)
```

## what it makes

two printed parts per board, both in one dependency-free `.scad` file (vanilla openscad, no libraries — also pasteable into web playgrounds):

- **case_bottom** — tray with floor and walls, standoffs under the board's mounting holes, a usb-c slot cut in the wall nearest the mcu's usb edge (derived from the placement rotation, not hardcoded)
- **top_plate** — switch plate: 14mm mx openings, 10mm encoder shaft holes, oled window, m2 screw holes

coordinates match the pcb's board coordinates: `(0,0)` is the board center, `+y` toward the usb wall.

## the sliders

the generated file opens with the named parameter block — these become the app's slider-based configurator (makerworld makerlab style): `pcb_width`, `pcb_height`, `case_margin`, `wall_thickness`, `base_thickness`, `corner_radius`, `front_height`, `rear_height`, `standoff_height`, `screw_size`, `plate_thickness`. derived values (usb slot size/position, standoff positions, plate openings) are emitted below them, regenerated by the engine when the board changes.

## component-driven, not example-driven

dimensions come from component metadata (usb-c shell 9.4 × 3.26, ec11 shaft clearance 10mm, mx plate opening 14mm), not from any reference keyboard. reference designs (hackpad etc.) inform practice only — see `scope/roadmap.md` standing decisions.

## validation

human words, never codes: "the usb port would breach the case floor — raise the standoff height above 4.3mm…", "this board has no mounting holes — the case cannot anchor the pcb…". case errors fail the job (retry rungs can't fix a design flaw); warnings ride along as artifacts.

## testing

```
KEEBERIA_OPENSCAD_BIN=/path/to/openscad npx tsx test/render.ts
```

without openscad it still generates + validates the scad for all reference layouts. with it, each case also compiles to a real stl — the honest check that the geometry is manufacturable text, not just plausible text. all three reference boards pass (hackpad-3key, ninepad, streamdeck).
