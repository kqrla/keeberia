# offerings

what keeberia lets you make. one folder per product family: macropads,
keyboards (incl. splits later), keycaps, clicketies (fidget clicky keys, no
typing function, see offerings/clicketies/README.md), cases, and types/, the
component taxonomy (switch types, mounts, etc.) that feeds the engines.
types/ is also where the planned switch guide + simulator live: for people
who can't tell a tactile from a linear by looking, a page where you can
press, feel, and hear each switch type.
