# keycaps

(one of keeberia's offering families, see /offerings/README.md. content
as the flows ship.)

two paths, two engines, one offering:

- **parametric**: paracraft's caps-engine. profile, dish, stem, legend,
  material, everything traces to a spec. the default path, ships with
  the layout-to-device flow.
- **artisan (capsmith)**: a decorative topper composed onto a paracraft
  base cap. croissant, waffle, bow, succulent, tiny objects. less
  configurable (pick a motif from a library, not a slider), more
  "which one do you want" than "tune this." see engines/capsmith/README.md
  for the composition model and open questions, nothing built yet.
