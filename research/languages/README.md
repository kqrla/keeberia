# language passes

> thesis: every language pass ships with its own evidence-backed corpus page: what physical board the language rides on, what logical layout it types through, what legends its keycaps need, and what is still unverified. the corpus lines live centrally in research/evidence/evidence.jsonl, these pages cite them by evid id and hold the per-pass open questions.

or simply put: before a language version turns on, this folder is the checklist of what is proven, what is designed, and what still needs a source.

## the three-way frame

each pass answers three independent questions, none derivable from another:

1. **language version** (the ladder in [../legends-multilingual.md](../legends-multilingual.md) section 5)
2. **physical standard** (ansi, iso, per-region iso variants: [../layout-standards.md](../layout-standards.md))
3. **logical layout** (qwerty, qwertz, azerty, jcuken, dubeolsik, inscript...)

the engine asks a buyer all three, never assumes one from another `[evid-lay-020]`.
