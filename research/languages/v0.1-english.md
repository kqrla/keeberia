# v0.1 english

> thesis: english is two keyboards, not one. us english rides the 101-key ansi board with the horizontal 2.25u return; uk english rides the 102-key iso board with the extra key between left shift and z, a shorter left shift, and the vertical iso return. v0.1 ships only if it asks which english.

## evidenced facts

- us-ansi vs uk-iso physical split: 101 vs 102 keys, extra key at left shift, return key shape `[evid-lay-020]`
- ansi horizontal return 2.25u with backslash above; iso vertical return spanning two rows `[evid-lay-001, evid-lay-002]`
- iso boards swap right alt for altgr for third-level characters, which uk legends use for currency symbols `[evid-leg-007]`
- apple mac boards are their own physical family: 78 us / 79 iso keys `[evid-mac-004]`
