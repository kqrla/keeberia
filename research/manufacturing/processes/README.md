# processes

planned research, in value order (each lands with evidence lines when written):

1. **pcb fabrication** — etching, drilling, routing/v-cut, plating; the finishes (hasl leaded/
   lead-free, enig, osp) and when each is right for a keyboard board
2. **smt assembly** — stencils, paste, reflow, hand-solder fallbacks; the parts-library problem
3. **defect modes** — tombstoning, solder bridges, lifted pads, insufficient hole fill;
   what our design rules are *defending against*
4. **case fabrication** — fdm/sla/sls, warping and tolerance, print orientation for plate
   openings, thread inserts vs self-tapping into plastic
